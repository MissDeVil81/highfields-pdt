---
name: Orval v8 query options
description: How to correctly pass conditional query options to Orval-generated React Query hooks
---

When using Orval v8 with TanStack Query v5, passing a `query` options object requires an explicit `queryKey` field. Omitting it causes TS2741.

**Rule:** Always import and use the matching `get*QueryKey` helper alongside any generated hook that receives `{ query: { enabled } }`.

**How to apply:**
```tsx
// Wrong — missing queryKey
useGetUser(id, { query: { enabled: !!id } })

// Correct
import { useGetUser, getGetUserQueryKey } from "@workspace/api-client-react";
useGetUser(id, { query: { queryKey: getGetUserQueryKey(id), enabled: !!id } })
```

The `get*QueryKey` helpers are auto-generated by Orval alongside every hook; they accept the same params as the hook itself.

**Why:** Orval v8 generates hooks where the `UseQueryOptions` type in the `query` overload requires `queryKey` to be present (it doesn't default it for you when you're providing a partial options object).
